# Hello World: Exercises & Practice

## Exercise 1: Your Own Hello

Write a program that prints your own greeting. (Not "Hello, World!" - make it your own.)

**Example output:**
```
Hey there, I'm learning Python!
```

**What to do:**
1. Create a new file called `greeting.py`
2. Write one `print()` statement with your own message
3. Run it with `python3 greeting.py`
4. See your message appear on screen

**Hint:** Use `print()` with text inside quotes.

---

## Exercise 2: Three Lines

Write a program that prints three different messages, each on its own line.

**Example output:**
```
Python is cool
I am a programmer
This is my first program
```

**What to do:**
1. Create a file called `three_lines.py`
2. Write three separate `print()` statements
3. Run it and verify all three messages appear, each on its own line

**Hint:** Each `print()` statement automatically goes on a new line.

## Exercise 3: Debug This

Here's broken code. Run it, read the error message, then fix it.

```python
print(Welcome to Python!)
```

After you fix it, the output should be:
```
Welcome to Python!
```

**What to do:**
1. Create a file called `debug1.py`
2. Copy the broken code into it
3. Run it and read the error message carefully
4. Figure out what's missing
5. Fix it
6. Run it again to verify it works

**Hint:** Read the error message. It tells you exactly what Python doesn't understand.

---

## Exercise 4: The Blank Line

Write a program that prints:
```
Top
(blank line here)
Bottom
```

Use `print()` with nothing inside to create the blank line.

**What to do:**
1. Create a file called `blank_line.py`
2. Write three `print()` statements:
   - First: print "Top"
   - Second: print nothing (empty parentheses)
   - Third: print "Bottom"
3. Run it and see the blank line appear

**Hint:** `print()` with nothing inside creates a blank line.

## Exercise 5: Error Detective

For each of these broken code snippets, predict the error, then run it to verify:

**Code A:**
```python
print("Missing close paren"
```

**Code B:**
```python
print(Hello)
```

**Code C:**
```python
print('Mismatched quotes")
```

**What to do:**

For each code snippet:
1. Create a file (e.g., `error_a.py`, `error_b.py`, `error_c.py`)
2. Copy the code into the file
3. Before running it, write down what error you think Python will show
4. Run it
5. Compare your prediction to the actual error
6. Fix the code so it runs without error
7. Run it again to verify the fix works

**Hint:** Re-read the error messages. They're very specific about what went wrong.

## Checking Your Work

After each exercise, ask yourself:

- ✓ Did my program run without error?
- ✓ Did the output match what was expected?
- ✓ Did I use proper syntax (quotes, parentheses, matching)?
- ✓ Can I explain what each line does?

If you got an error, don't skip it—read the error message and fix it. Errors are how you learn.
